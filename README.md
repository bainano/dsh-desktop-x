# DeepSeek Harness Desktop

对 DeepSeek-harness 做过一定的优化和修改，打包成的 Windows 桌面版，一键安装即可使用，与网页版数据通用。

## 核心特性

- **本地优先**：数据与模型请求都在你的机器上完成，不依赖云端中转，数据不出设备。
- **兼容网页版**：直接复用网页版数据，不会重新初始化，无迁移成本。
- **插件化运行时**：继承 deepseek-harness 原生插件体系，启动即加载，按需扩展工具与数据源。
- **一键启动**：内置 Node 运行时与依赖，双击即用，无需手动安装任何环境。
- **桌面原生体验**：原生窗口控制按钮、系统圆角、顶部可拖动，深色模式自动适配。
- **两种交付形态**：提供 NSIS 安装版与 portable 便携版，随取随用。

> 说明：首次启动稍慢；链接手机等功能开发中。
